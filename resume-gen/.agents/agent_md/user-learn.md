# User Preferences — resume_ui_v2

## Design Philosophy

- Strongly prefers **premium, understated professional quality** over flashy decoration
- Wants generated documents to feel **human-crafted in Word**, not machine-generated
- Values **whitespace and breathing room** — no cramped layouts
- Prefers **typography and spacing to create hierarchy**, not colors or decorative elements
- Uses the phrase "make this awesome" to indicate high quality bar is expected

## Workflow Preferences

- Uses `/goal` to indicate long-running thorough tasks — proceed without waiting for approval on subtasks
- Prefers **minimal command execution** — batch commands at the end rather than running them eagerly
- Prefers **clean white themes** and **monochrome palettes** for professional documents
- Prefers **production-ready solutions**, not placeholders or quick fixes

## Reference Materials

- `SEO_Indexing_Architecture.docx` in project root is the reference document for the Word aesthetic
  - Key features: Calibri font, thin bottom rules under section headings, no colored bars, generous spacing, all-caps section titles

## Communication

- Prefers implementation first, then explanation
- Approves implementation plans via the artifact feedback UI before execution
